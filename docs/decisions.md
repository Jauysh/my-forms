# Архитектуралық және стратегиялық шешімдер (Decisions Log)

Бұл құжат жоба барысында қабылданған барлық негізгі технологиялық және концептуалды шешімдерді тіркейді (Architecture Decision Records - ADR).

---

## ADR-001: Құжаттама мен Чат тарихын сақтау стратегиясы
* **Күні**: 2026-10-13
* **Мәртебесі**: Қабылданды (Accepted)

### Контекст:
Жобаны бастамас бұрын жан-жақты талқылау және оның нәтижелерін Git репозиторийінде сақтау қажеттілігі туындады.

### Шешім:
1. **Екі деңгейлі құжаттау жүйесі енгізілді**:
   * **1-деңгей (Жедел қарау үшін)**: Негізгі шешімдер, талаптар мен архитектура арнайы Markdown құжаттарына жинақталады (`docs/requirements.md`, `docs/architecture.md`, `docs/decisions.md`).
   * **2-деңгей (Терең диагностика үшін)**: Талқылаудың толық контексті мен диалог тарихы `docs/chat_history.md` файлына жазылып отырады.

## ADR-002: Негізгі технологиялық стек (Tech Stack)
* **Күні**: 2026-10-13
* **Мәртебесі**: Қабылданды (Accepted)

### Контекст:
Формалар құрастыруға, сауалнамаларды жариялауға және жауаптарды өңдеуге арналған сенімді, заманауи әрі масштабталатын стек таңдау қажет.

### Шешім:
* **Нұсқаларды бақылау (VCS)**: Git & GitHub (`https://github.com/Jauysh/my-forms.git`).
* **Контейнерлеу**: Docker (локальді ортаның тұрақтылығы мен тестілеу үшін).
* **Хостинг / Деплой**: Vercel (Edge network, CI/CD автоматты жариялау, жоғары жылдамдық).
* **Бэкенд және Дерекқор**: Supabase (PostgreSQL, Supabase Auth, Row Level Security (RLS), Storage).
* **Фронтенд**: Next.js (TypeScript, Tailwind CSS, shadcn/ui).
